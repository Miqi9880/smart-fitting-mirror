## 多件叠穿现在会怎样

当前 `TryOnModel.outfit` 按 category 保存一件，`TryOnView.setOutfit` 拒绝重复类别；绘制顺序是裤子 → 上衣 → 帽子。因此当前可以上衣＋裤子＋帽子组合，第二件上衣会替换第一件，不是内搭与外套叠穿。

后续做两层上衣时，需要内搭／外套层次、独立定位和有效透明区域：闭合外套覆盖内搭大部分区域，内搭只在领口或外套之外露出；敞开外套的开口必须保留透明，才能露出里面的 T 恤。仅把两张完整图重叠，会出现后画的挡住前画的、衣领／袖子错位等问题，不能当作真实布料叠穿。

现有生成任务也只接受单件 `garment_id`，仍为 MOCK。真实 API 是否支持多件／整套需按实际提供方确认，不因原图库变大就宣布支持整套生成。真人贴合仍要主动开启真实 RGB，由负责人或 lyf-bee 用电脑摄像头接模拟器／合适手机复核，不强制由负责人独自验证全部 51 张。
