## 当前落地的迁移

上游 `MediaPipeBodyTracker.processMediaPipe` 对相邻关节用 0.6 的当前测量权重做指数平滑。本项目已将该块适配为 `PoseStabilizer`，接入 `CameraRgbSource` 的真实模型输出：

```text
CameraX 当前图像
 → ML Kit 推理完成
 → PoseMapper：过滤低置信度和出界点，归一化
 → PoseStabilizer：只平滑当前有效点的 x/y
 → 当前 VisionFrame / FrameLease
 → 诊断或试衣渲染
```

意图是减小小幅测量跳动，代价是平滑会带来一定跟随滞后；0.6 来自上游初值，真人效果需实测调校。没有声称本次已经解决所有真人抖动或提升识别准确率。

适配时特别处理了上游不适合直接沿用的行为：

- 缺失/低置信度点当帧就变 null；lost 输出没有旧点，恢复点直接使用新测量。
- confidence 保留当前测量，不因历史存在而提高；depth/mask/distance 仍保持现有未知值。
- 每个相机 Run 独立；停止时清理，尺寸变化、超过 250 ms 间隔或时间不递增时不混合历史。
- 当前图像与当前推理回调一起交付，不使用“最新异步结果”去配另一张新帧。
- 模型或相机失败继续报告错误，没有移植其模拟 T-Pose / 固定 1.5 m 深度回退。

公开数据合同、模块职责、帧所有权和 HTTP 行为没有变化；调用方无需迁移字段。合成源仍按原来的确定性场景输出，不经过本滤波器。
