# 模拟后端验证记录

日期：2026-10-09。范围：T03 的本地模拟服务、原创演示素材和 HTTP 合同。没有接入真实 AI，也没有将结果当作真实试衣质量证明。

## 已执行

Windows、Python 3.12.14、backend/requirements-dev.txt 固定依赖。`python -m pytest backend/tests -q --junitxml=backend/test-results.xml` 共 35 项通过：32 项合同与行为检查，3 项启动独立 CLI 子进程并通过真实回环 HTTP 的检查。

| 范围 | 证据 |
| --- | --- |
| 七个操作及素材/结果下载 | 成功完整流程返回合同所需字段；透明 PNG 可读取，尺寸/锚点有效 |
| 幂等 | 12 个并发相同创建请求只建立一个任务；不同输入同键 409；已绑定请求重放不消耗新任务配额 |
| 终态 | 先取消与先完成两种顺序均不回退；取消后无结果图 |
| 模拟场景 | 成功、失败、15 秒延时、120 秒超时和首次 429；时限边界用可控时钟验证 |
| 隔离/清理 | 跨会话上传、任务与结果被拒绝；结束及重复结束；无后续请求时后台到期清理；上传解码期间结束不会恢复旧会话 |
| 输入 | MIME 与实际类型、损坏图、唯一 file 字段、10 MiB/1600 万像素边界、EXIF 方向与元数据去除 |
| 容量 | 存储/会话配额、分块请求体上限、并发上传超限在读入文件前返回统一 429 |
| 真实 HTTP | CLI 的 success、failure、rate-limit 均完成上传、幂等重试、轮询、取消、隔离与撤销检查；不是只调用 Python 内部函数 |

本机 pytest 默认临时目录无读取权限，验证改用工作区中的 PYTEST_DEBUG_TEMPROOT；未修改系统临时目录权限。固定版本的 Starlette 对 httpx 测试兼容层产生一条弃用警告，35 项测试均通过，真实 HTTP 检查不依赖 TestClient。

素材蓝色上衣已直接查看，另以测试检查三件图像的 RGBA、尺寸、透明背景和四个锚点位置。素材是项目原创几何图，用于联调，不是生产服装素材。
