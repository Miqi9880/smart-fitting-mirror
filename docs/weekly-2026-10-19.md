## 环境、素材和提交流程

Android沿用Android Studio、JDK17／21、SDK35和仓库Gradle Wrapper；后端沿用Python3.12与`backend/requirements-dev.txt`。无须为了这些任务安装训练环境、Unity、Blender或购买安卓手机。第一次配置按[入门](getting-started.md)；已有环境无需重配。

先保存自己未提交的改动，再更新main、开个人功能分支；不要强制重置。透明包到手后在仓库根目录执行：

```powershell
python tools/install_studio_assets.py "smart-fitting-mirror-studio-assets-20261021-v3.zip"
python tools/install_studio_assets.py --check
python -m backend --port 8000 --catalog-db data/catalog.sqlite3
```

模拟器填`http://10.0.2.2:8000`；连接服务不打开相机，成员本轮可选合成源。缺包时向负责人要v3运行包，不把JPEG原图包解压冒充透明图；面片软件复现可以先用程序生成测试图。包不公开上传Git／Release，负责人负责课程内交接。

按影响运行检查：后端`python -m pytest backend/tests -q`；合同／文档`python tools/check_contracts.py`；渲染变更在android目录运行`:feature-tryon:testDebugUnitTest :feature-tryon:lintDebug :app:assembleDebug`并执行相关模拟器绘制检查；页面改动运行`:app:lintDebug :app:assembleDebug`及新增行为的模拟器检查。提交前`git diff --check`。纯文档不要求Android重构建；没有改动、失败或新问题不机械重复已完成检查。

每项交PR写：关联Issue、实际修改、本人执行的命令／结果、模拟还是现场、尚缺条件。人像、录像、结果图、密钥和会话凭证不入Git。测试证据不冒充另一成员本人执行，合成／模拟器性能不冒充镜子性能。
