## 环境和验证

沿用 [环境入门](getting-started.md)。Android Studio＋JDK 17/21＋SDK 35＋Gradle Wrapper；后端沿用已验证的 Python 3.12 环境，已装好者不重复安装。素材处理可用已有 GIMP/Photoshop 等本地图像编辑器。此周不要求 Unity、NDK、CUDA、深度 SDK、训练模型或付费 AI。

Android 手机先打开获准的 USB 调试并用数据线连接。`adb devices` 需出现 `device`，手机确认自己的调试授权；手机相机权限需实际允许。电脑服务在仓库根目录：

```powershell
.venv\Scripts\python -m backend --host 127.0.0.1 --port 8000 --mode success
```

服务终端保持运行；另开终端执行 `adb reverse tcp:8000 tcp:8000`。真机 App 填 `http://127.0.0.1:8000`，官方模拟器填 `http://10.0.2.2:8000`；`reverse` 只转发服务端口，不会把相机变成真人输入。

在 `android` 目录使用 ` .\gradlew.bat :app:assembleDebug` 构建。每人改动自己的模块后跑相关 `testDebugUnitTest` / `lintDebug`；后端运行 `python -m pytest backend/tests -q`。合同与文档用 `python tools/check_contracts.py`，提交前 `git diff --check`。涉及图片绘制、相机或页面行为须补相应 Android 仪器/人工验证，不能只拿 Python 几何测试替代。

记录 commit、手机/系统、输入来源、服装 ID、执行步骤和通过/失败/未执行。真人画面留在本机，公开报告用数值/步骤与不含人像的材料；授权范围明确后再决定可共享的影像。原始帧不得烧录衣服或调试点，结束/切源要释放旧帧，拍照上传仍由用户主动触发。
