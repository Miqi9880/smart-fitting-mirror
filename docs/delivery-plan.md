## 交付节点按成果触发

1. 当前可运行基线随时保留。每批素材／接口／算法改动必须有适用检查和可审阅小 PR，条件具备即合并并继续下一项，不等周末或排期中的某周。
2. 新增类别与公共字段先在同一功能 PR 对齐服务端、Android、合同和样例，明确版本；本轮HTTP0.3.0与Android已同步支持六品类，视觉帧仍为0.2.0；后续计划不冒充已经发布。
3. 真实 API 和真人预览各自独立验收；随后做目标镜子端到端、性能和异常恢复。硬件未解决时软件可以前进，目标设备验收保持未完成。
4. 发布以版本为单位安排短暂稳定检查、回归和可回退配置，不设置学期冻结周。新的硬性日期由负责人实际确认后更新。
