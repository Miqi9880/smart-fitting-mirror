# 预训练试衣模型的服务器资源预估

2026-10-23：负责人计划下载已有模型，再独立微调。模型、训练代码、数据量、分辨率和批量尚未确定，以下是申请资源的工程估算，不是项目已实测的最低配置。当前 Aidge/COS API 主线不需要本项目占用服务器 GPU。

| 用途 | 可先申请的单卡显存 | 范围 |
| --- | --- | --- |
| 轻量模型原权重推理 | 12–16GB | 先跑单张、小批量；部分模型可更低，不据此推断训练也能装下 |
| 小规模 LoRA／部分参数微调 | 24GB 起步 | 先选兼容训练实现，batch=1、混合精度、梯度检查点／累积，先验证一个训练步和验证出图 |
| 模型尚未定、希望保留调参余量 | 优先48GB；40GB可评估 | 更适合申请学校现有资源；不保证任意 SDXL／高分辨率全参数训练都能单卡运行 |

这是单张卡的显存，不是服务器运行内存，也不能把两张24GB直接当作一张48GB使用。先核对能够分配给我们的卡和空闲显存，再决定是否需要多卡训练代码。

证据与限制：

- [CatVTON官方仓库](https://github.com/Zheng-Chong/CatVTON)给出1024×768、bf16推理约8GB显存；这不是通用微调需求。
- [CatVTON论文](https://arxiv.org/html/2407.15886v2)表4在batch=1的特定实验中报告自注意力训练Memory(M)=8451；该实验不能直接等同我们尚未选择的训练脚本、分辨率或预处理流程。24GB／48GB是留有余量的资源建议，不宣称论文要求这些容量。
- [IDM-VTON官方训练脚本](https://github.com/yisol/IDM-VTON/blob/main/train_xl.sh)示例使用4张GPU、每卡batch=6，并启用梯度检查点和8bit Adam。不能照抄示例后承诺单卡24GB必定可训练。
- 48GB示例为[NVIDIA RTX A6000](https://www.nvidia.com/en-us/products/workstations/rtx-a6000/)。也可使用老师已有的其他CUDA兼容卡，不要求购买某个型号。

配套建议：Linux、8个以上CPU核心、64GB运行内存（32GB可先小规模验证）、约200GB可用SSD空间；根据数据集与检查点数量调整。提供独立Conda／容器环境、SSH或学校规定的任务调度入口，以及可下载模型的网络。Python／CUDA／PyTorch版本依所选模型确定，不强制沿用公共后端Python3.12。

请老师提供当前可分配GPU型号、每卡总／空闲显存、可使用时段或作业时长上限、运行内存、可用磁盘及远程登录方式。可由管理员运行：

```bash
nvidia-smi --query-gpu=name,memory.total,memory.free --format=csv
```

拿到配置后先跑原模型推理与显存监测，再做一个训练步，测峰值显存与每步耗时，然后决定微调规模。训练数据需要人物穿着图、对应服装图及模型所需标注／遮罩；当前官网商品素材库不能单独充当配对训练集。微调不阻塞团队API主线，也不提前修改Android公共接口。
