## 两条质量路径

实时预览由端侧关键点、素材锚点、几何形变、分割／遮挡输入和交互校准共同改善，主要对应FR-VTO-04。服务器生成是用户主动提交照片后得到精细结果，对应FR-VTO-05及06。部署生成模型不能自动修复每帧贴图粗糙，不逐帧调用生成服务。

已完成标准模特及镜子真人的历史Aidge生成，见[提供方修复](reports/provider-recovery-2026-10-23.md)和[历史现场记录](reports/mirror-real-generation-2026-10-23.md)；10/24已暂停。#53已补7条参考视频与同一App播放，不把本轮重新部署当作这些功能未完成。

## 负责人部署：先推理，再决定微调

1. 选择一个可支持上衣的现成模型，核对代码、权重和样例许可／使用范围、实际预处理及Blackwell兼容性，不照搬旧版PyTorch依赖。公共后端Python3.12不强制训练环境用同版本。
2. 先建独立环境、验证GPU小张量，再跑一组获准人物图＋服装图；余量足够时扩展5组固定评估。记录环境、权重／代码版本、分辨率、随机种子、预处理、耗时、峰值显存和失败案例。
3. 仅部署权重不算微调。固定基线后，按领口／袖口／腰线／纹理／遮挡问题和数据条件决定LoRA或部分参数微调；没有适合的配对数据不从训练开始。现有官网服装图不能单独构成配对训练集。
4. 人像、权重、检查点及生成结果受控保存，不提交普通Git。使用获准CG／公开样例起步，真实镜子照片传到服务器前需明确授权，不自动迁移旧人像。

## 已核对资源与`/data_new`

10/30及11/1核对服务器可通过SSH使用，Ubuntu22.04、96逻辑线程、约256GB运行内存，2张RTX PRO5000 Blackwell，每张约48GB显存，CUDA12.8与驱动初始化通过。1号卡检查时约47GiB空闲，0号卡有占用；这不是使用时段预约，也不把两卡显存当作一张96GB。默认Python3.10环境未发现PyTorch，Hugging Face直连检查失败；资源申请估算见[GPU规划](gpu-planning.md)。

用户明确要求数据放`/data_new`，统一项目根为`/data_new/smart-fitting-mirror`：

```text
/data_new/smart-fitting-mirror/
  envs/         独立模型环境
  src/          模型源码与部署脚本
  models/       预训练权重与版本清单
  datasets/     授权数据与分割／姿态等预处理
  eval/         固定评估清单／非训练样例
  outputs/      受控推理结果
  checkpoints/  后续小规模训练检查点
  cache/        Hugging Face／Torch／pip等缓存
  tmp/          受控临时目录
  logs/         脱敏运行指标
```

11/1目录创建曾因权限被拒；11/2老师授权后已建立项目根和上述10个子目录，普通账号读写／删除探针通过，权限阻塞解除。当前路径落系统盘ext4，约435GiB可用，并非新增独立数据盘；详见[11/2目录复核](reports/server-storage-2026-11-02.md)。模型环境／权重尚未部署。

接下来创建独立模型环境时，将HF_HOME、HF_DATASETS_CACHE、TORCH_HOME、XDG_CACHE_HOME、PIP_CACHE_DIR和TMPDIR显式放到上述cache／tmp下；本次只建立目录，尚未配置这些变量或下载权重。权重／环境／数据／结果都不回落home，模型／许可／依赖与下载可达性继续核对。服务器IP、账号、口令不放Issue、PR或日志。

## 提供方接入边界

公共App／会话／上传／任务／对比／清理继续共用，不重写Android或公共HTTP。后端haiyangniu191-design先按[本地推理内部草案](interfaces/local-model-draft.md)交独立适配组件和fake测试，暂不注册公共CLI／默认服务，不把测试图当真实模型输出；负责人维护GPU模型服务。

```text
Android同一App → 公共后端（会话／幂等／预算／清理）
                   → MOCK（当前默认）
                   → Aidge/COS（保留代码，当前暂停）
                   → 本地模型适配组件（待模型验收后另PR启用）
                        → 负责人独立部署的GPU推理服务
```

实际接入至少先满足：原模型可复现出图；输入品类、图像处理、预算／失败／取消／结果清理已说明；固定评估和真实资源记录齐备；当前使用许可清楚。内部服务仅loopback，通过负责人受控连接访问；不对公网直接开放无鉴权服务。客户端取消不等于GPU算子已中止，实际占用互斥和迟到处理必须另验。

模型就绪后由负责人协调真实集成PR，补公共服务启用方式、匿名统计分类、单任务互斥和主线回归。此前不提前改公共合同或增加双引擎页面；微调不作为成员任务或本周共同交付前置。企业5—15秒生成、Depth／mask精细遮挡和长期稳定性尚未据本计划达成。
