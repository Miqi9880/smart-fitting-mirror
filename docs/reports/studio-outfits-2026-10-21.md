# 官网素材与三品类组合预览验证

2026-10-21。基线 main `d885376`，分支 `feat/real-outfit-catalog`。由负责人委托补位完成，不计作其他成员个人已实现或共同验收。[功能与复现](../studio-outfits.md)。

## 变更

默认目录的三件合成上衣和皱褶白 T 恤退出正常展示，替换为官网黑/蓝/红平铺 T 恤、长裤和针织帽。旧素材仅用于显式 regression 目录及历史报告。品牌 PNG 置于 Git 忽略的本地素材包，元数据、来源与 SHA-256 入库；安装器完整验证后写入，缺包报可操作错误。

视觉从八点扩到十四点，新增双膝、双踝和双耳；HTTP/视觉帧均升至 0.2.0，能力 Schema 不变。裤子用同帧髋/膝/踝分段贴图，帽子用双耳相似变换；各品类缺点独立隐藏。三品类组合保留、同类替换、移除/清空、旋转恢复及 Bitmap/帧释放一并接入。

## 检查中发现的修正

- 初次几何测试发现交叉双腿仍可形成局部有效三角形，增加当前帧的腿序/退化检查，避免错误拉扯裤子；复测通过。
- 初次组合交互测试未能加载全部三件：旧 preview 方法刻意只允许当前选中单品，切换选择会取消旧图。新增 outfitPreview，允许同会话当前衣柜中的多个单品，仍拒绝已删除/变更条目及已结束会话，迟到字节清零；原单件接口保持原语义。针对测试及完整套件通过。
- 主动连接服务不再隐式启动已获授权的 RGB 相机，显式选择 RGB/合成源后才开始；新交互测试覆盖该行为。
- TestClient 在固定依赖下仍有一条 httpx 兼容层弃用警告，50 项测试通过；不将警告说成没有。

## 限制与接手

真实人体穿着贴合、目标镜子摄像头/ABI、大屏真人站位、帧率与长期稳定性尚未据此验收。品牌图为辅助去背景版本，细节/边缘与初始锚点仍需人工和真人复核。帽子为正面双耳定位，不具备精细头发遮挡；裤子为二维分段贴图，不测尺码或布料物理。腰带和耳环不在本轮已交付品类内。云端生成仍为选中上衣的 MOCK，不生成真实整套搭配。
