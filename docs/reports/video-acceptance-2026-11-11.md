## 本地复验

在安装了视频包和 `backend/requirements-dev.txt` 的环境，从仓库根目录执行。

```powershell
python tools/check_video_acceptance.py
python -m pytest backend/tests -q
python tools/check_contracts.py
```

覆盖工具使用临时数据库和本地测试客户端。当前返回退出码 1，表示至少一个服装上下文不足 5 条。Android 联调使用本机 MOCK 与已安装授权包，先从试衣页选上衣，进入「当前搭配相关视频」，选风格偏好，再验证推荐更新、来源、横竖播放、暂停／下一条、返回及结束清理。

## 镜子现场待验

1. 确认验收服务安装同一视频包。在镜子进入「相关视频」，验证风格选择、来源说明和服装上下文切换。验收当天记录版本、实际候选数和视频 ID。
2. 对不同方向的视频确认触摸、实际画面、默认静音、暂停、下一条与返回。实际音量需要带音轨的获准内容。现有 7 条已去音轨。
3. 在镜子确认键盘焦点、真实 TalkBack 朗读和长时间播放。结束体验后确认播放器关闭并返回待机。
