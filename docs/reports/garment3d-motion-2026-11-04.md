# 蓝色 T 恤四动作修正与复核

2026-11-04。用户指出第一件 3D 样件抬臂时衣身被扯成大三角形；本次只修正这一件的合成人台验证，不扩充品类、不改 Android 正式链路或其他成员当前 PR。

**后续反馈：** 本记录是 v2 的历史检查，数值通过没有覆盖近景外观缺陷。用户随后指出袖子褶皱像裂开、袖身衔接不正常；已继续按 [v3 袖身衔接修正记录](garment3d-junction-2026-11-04.md)处理，不能将本页的历史结果称为用户已认可或正式验收完成。

## 问题与最终处理

v1 把商品图轮廓加前后体积，按横向位置分配少量骨骼权重，衣身多数位置保持根骨骼，袖子旋转后连接面被拉长。原 A 姿态网格的局部边在抬臂终点达到原长约 6.85 倍，P99 约 2.97 倍；不能把这样的运动当成合格试衣。

v2 从名义 T 姿态建立可绑定的中性服装结构，使用均匀内部采样和受边界约束的三角剖分，避免大扇形细长网格；商品图只保留为正面 UV 输入。统一骨架和人台代理后，用姿态引导、XPBD 拉伸上限/柔性弯曲/袖口约束和代理碰撞修正网格，衣身与下摆可随约束移动。未校准真实面料，也未实现完整布料动力学或自碰撞。

逐帧 CPU 预计算站立、抬臂和前伸；浏览器播放修形位置并使用同一片段帧驱动人台。切换时沿当前片段退回站立再进入下一动作，消除人台先换姿态而衣服还停在旧姿态的交错。转身为衣服/人台整体旋转，支持 ±180°；没有宣称转身布料惯性已模拟。

背面/侧缝使用原图中央布面区域的 UV 采样，改善纯色背面与正面突然分界；这是近似材质，缺少真实商品背面资料。原 PNG 没有改像素，也没有声称生成了真实背面。

## 数值复核范围

默认 2,154 顶点、4,188 三角面。183 个位置样本：站立 1 帧、抬臂 91 帧、前伸 91 帧，含动作过渡和末端保持；回程/循环反向播放同一数据。抬臂肩部旋转保留原测试幅度 1.05 rad，前伸肩部 0.60 rad、肘部 0.65 rad。

边长统计以新中性网格为基准，仅统计原长 >8 mm 的 6,081 条边，侧缝厚度边不算布料伸长。重建前后的网格和基准不同，这些数值是各自名义模板的几何畸变检查，不能解释成真实面料试验。

| --- | --- | --- | --- |
| 站立 | 1.0884 | 1.2853 | 0 |
| 抬臂全部帧 | 1.0884 | 1.2853 | 0 |

## 软件验证与产物

- `npm test`：模板有效性、四个开口、骨骼及动作切换/返回/循环时序。
- `npm run test:motion`：不依赖图片的完整动作重算，检查全部样本的畸变、代理表面采样及相邻帧位移连续性。
- `npm run test:sample`：独立 Khronos GLB 校验、原 PNG 字节摘要、动作和模型几何/文件摘要与片段边界一致。
- Python 路由测试：限定路径、秘密文件/目录/穿越读取拒绝。
- 浏览器复核站立、抬臂、前伸、转身及正/侧/背视角，检查切换/循环、人台/线框、窄窗口与桌面控件。截图保留本机忽略目录，不上传品牌纹理衍生物或真人图片。

基础 GLB 包含中性 T 姿态网格与骨架，已移除 v1 的错误纯骨骼抬臂动画；修形数据单独保存在 `motion.bin`/`motion.json`。前端检查版本、顶点/字节数及模型几何摘要，避免新旧资源混用。依赖、复现和更多限制见[工具说明](../../tools/garment3d/README.md)。

## 交付边界

页面 FPS 是桌面播放预计算网格的渲染表现，不代表实时布料求解，更不代表镜子通过 15/20 FPS 指标。尚未接摄像头、真人姿态/体型、真实遮挡、Android 3D 渲染或目标镜子；此次没有上传人像、调用付费 API 或下载模型权重。企业 FR-VTO-04 等 P0 验收项不因该合成样件自动完成，#6/#26 不关闭。

下一步先由负责人检查这件样件的四个动作外观；只有确认值得沿用，再接运行时真人驱动与镜子性能，不批量制作未经确认的同类模型。
