## 交付与边界

保留首页原 `home.garment3d` 实验入口和原常规二维试衣。实验页新增原生「姿态回放（非真人）」「开启真人驱动」、相机通道、镜面显示、关键点和返回人台。进入页、回放、返回前台均不会自动开摄像头；相机只从明确按钮和权限路径启动。后台/退出/切换通道/渲染异常停止采集与驱动，回到前台需要重新点按钮。

连续链路为：现有 CameraX / ML Kit → 同帧 RGB 与 `ImagePoseHints` → 有界内存编码 → 固定离线 WebView → 肩髋拟合与独立双臂骨骼 → 实时约束修形。真人模式不选择旧站立/抬臂/前伸片段。回放也是独立左右臂、位移和缩放的解析输入，经过同一帧编码/传递/渲染路径，但**不是从真人图像推理得到的姿态**。

`VisionFrame`/公共 HTTP 不变。新可选图像提示只供实验：x/y 归一化，z 按图像宽归一化。Google 明确说明 [ML Kit 的 z 是实验性的图像相对值，并非真实三维测量](https://developers.google.com/ml-kit/vision/pose-detection?hl=zh-CN)。这里使用弱透视、名义体型和相对 z 做初步拟合；没有启用 Gemini 深度、标定人体尺寸或得到精确商品尺码。

- 画面与模型使用同一未镜像帧坐标及 contain 裁切；镜像同时作用于画面、模型、遮挡和可选黄色关键点，不交换解剖左右标签。横竖屏共享源图比例。
- 双肩/髋/肘/腕置信度与几何守卫不足时隐藏衣服并提示入镜，不保留上一副骨骼冒充继续跟随。侧身过窄或背身拒绝拟合；完整转身不在本轮通过范围。
- 实际网格连续蒙皮并运行 16 轮距离/弯曲约束与代理接触，再做 4 轮拉伸限制。GLB 多材质 primitive 先恢复完整缝合索引，求解使用独立静止网格，不把输出当作下一帧绑定姿态。
- 前臂使用只写深度的胶囊代理，露出背景中的真实手臂。这是近似遮挡，没有人物分割、手指/头发精细轮廓、自碰撞或真实面料标定，不能声称已消除全部穿插和褶皱问题。
- 最长边缩到 640、JPEG 78；原生入口最多 10 帧/秒、最多一个编码/JS 发送在途，不排队累积帧。JS 解码同样有界，校验会话/帧序/尺寸；迟到、重复及旧会话拒绝。输入速率上限不是实测端到端帧率。
- 画面只在内存传递；无 JPEG 文件、HTTP 上传或 page-to-native JS 接口。沿用 APK 固定 HTTPS origin/资源白名单/禁网/禁止文件 URL；帧以可撤销 blob 显示。1.2 秒断流清除衣服、关键点和旧背景；原视觉源的首帧/断流看门狗保留。后台、停止、退出及渲染异常同样清除，返回不重启相机。

## 软件验证

环境：JDK21 / Gradle8.11.1 / SDK35；API35 Android15 x86_64 模拟器，系统 WebView124.0.6367.219、SwiftShader，前后摄像头参数均为 `none`。横屏1920×1080/density240，并切换竖屏。品牌样件与截图只留负责人本机；CI 不分发含素材包 APK。

- Node 几何/动作时序/生命周期及连续驱动共17项通过，含独立左右臂、前伸相对深度、肩髋投影、低置信度、旧会话和45个非预计算连续姿态的有限坐标/变化检查。
- App 35项与core-vision 33项JVM、构建及lint通过；新增3项回放/背压/过期回调与2项图像提示映射测试。
- 模拟器连续帧2项仪器测试：实际蓝色网格像素，独立骨骼变化，镜像/关键点开关、横竖屏、停止、后台清图且不自启动，低置信度隐藏和断流清图。
- 原人台离线动作、背景暂停、竖屏、渲染进程退出重试及首页返回感应关闭2项回归通过；最终4项合跑通过（48.958秒）。缺包构建及1项入口负向检查通过（2.608秒），随后恢复含包APK；不以缺包APK替代含包演示版本。
- Python本地路由2项及公共合同检查通过。初次新Node测试误将 `buildGarment()` 当成对象解构，已修正夹具；没有放宽质量阈值来掩盖失败。

仪器测试由程序调用控件，不能替代人的触摸和外观判断。模拟器截图是明确标记的 CG 回放；渲染帧率也不是镜子性能或真人识别速度。实时求解的有限值/小步连续性检查不等于旧离线183帧的全部外观指标已在任意真人姿态下通过。
