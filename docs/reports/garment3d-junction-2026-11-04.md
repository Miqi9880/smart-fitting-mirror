# 蓝色 T 恤袖身衔接修正

2026-11-04，v3。负责人指出 v2 前伸时袖子像裂开，抬臂时袖子与衣身衔接不正常。本次继续修单件本地合成人台样件，未修改 Android、正式实时试衣或其他成员 PR。用户尚未对本次外观复核给出结论。

## 原因与改动

1. **袖口不是共面的圆环。** v2 下半圈仍混入衣身变形，沿袖子轴向偏移约 13.3 cm；求解后就形成翘起的三角片。v3 让袖子外段完整进入圆柱截面，袖笼到衣身使用平滑过渡，袖口成为半径 8 cm 的共面圆环。圆环随骨骼目标固定，近似加强边；不声称模拟了柔软袖口。
2. **照片透明裁切被当成 3D 布面孔洞。** v2 正面使用 alpha MASK；去背景边缘的透明像素在腋下显示成假裂口。v3 改用不透明布面，开口由真实网格拓扑决定；只读原 PNG 的 alpha，将正面边界 UV 向内移至 6 px 的不透明邻域，共调整 58 个顶点。PNG 像素与嵌入字节不变。
3. **平铺袖子的阴影粘在运动袖子上。** 纯蓝袖子改用原图中央布面纹理，逐渐过渡到衣身，避免将商品图的深色袖褶当成永久的立体折口。这是纯色近似，花纹、Logo 和实际背面仍需要独立资料及 UV 处理。
4. **只推顶点不能阻止面片穿过手臂。** 增加肩部/腋下边中点及面中心接触约束，按自由顶点的重心权重分配修正，不移动固定袖口。与拉伸/弯曲约束交替迭代；碰撞代理外扩 5 mm，保持与显示人台一致的基础尺寸。
5. **远景不足以检查衔接。** 页面新增「细节」近景，复核肩缝、袖笼、腋下和袖口。保留正面、立体、侧面、背面与线框检查。

仍为 2,154 顶点、4,188 三角面和四个完整开口，没有拼上独立袖管或用不透明补片遮盖缺口。预计算使用 128 次迭代、姿态跟随系数 0.02；删除原先软袖口求解参数，避免其与实际固定边界含义不符。

## 外观与交付边界

本次针对截图中的尖片、假透明裂口及袖身穿插。肩缝仍可能出现低面数折线和近似材质接缝，未制作真实布料细褶、面料垂坠、自碰撞或转身惯性；背面也不是商品扫描重建。数值检查不能替代负责人对外观的判断。

当前动作是 CPU 预计算后播放，GLB 本体仍为中性 T 姿态。新增近景和桌面渲染帧率不代表已经接入镜子、支持真人或满足端侧性能指标；没有打开摄像头、上传图片、调用付费 API 或下载神经网络权重。#6/#26 和企业 P0 验收项保持原状态。
