# 试衣结果语义标签

在本机 Ollama 上运行 Qwen3-VL 2B Instruct，模型为 Q4_K_M。按需分析游客已生成的试衣结果，输出风格、适合场景和服装主色。模型输出只接受枚举值。缺乏视觉依据的字段允许空值。

普通推荐继续使用衣柜标签和主动风格偏好。用户选择「AI 分析生成图并推荐」时，客户端发送已有任务的 ID。后端核对会话归属与生成状态，用回环地址将结果送给本机模型。首次成功输出在该任务内复用，会话结束后撤销结果和标签访问。模型忙、超时或输出无效时返回规则推荐。

## 本机试验

使用同一标准 CG 模特的 4 张已生成结果，图像缩到最长边 512 像素。第一次调用含模型载入。用时为直接调用本机模型的端到端时间。

| 样例 | 风格 | 场景 | 服装颜色 | 耗时 |
| --- | --- | --- | --- | ---: |
| 白色印花短袖与黑裤 | 休闲 | 日常 | 白色、黑色 | 15.00 秒 |
| 红色宽松短袖与黑裤 | 简约 | 日常 | 红色、黑色 | 12.61 秒 |
| 灰色衬衫与牛仔裤 | 休闲 | 日常 | 灰色、蓝色 | 13.30 秒 |
| 黑色连衣裙 | 简约 | 日常 | 黑色 | 13.56 秒 |

模型在这组图上区分了颜色和部分风格，场景均归为日常。通勤、聚会、户外与风格边界需要继续用有明确参照的样例复测。候选数量仍取决于授权视频覆盖。

Android API 35 模拟器通过了同一会话的生成结果 → 主动分析 → 标签和推荐依据 → 结束清理。联调后端以已获准的白色印花短袖 CG 生成图作为固定结果，Ollama 实际读取该图并返回标签。整条模拟器测试约 24 秒，包含操作及等待。Android 未开启摄像头。后端另用受控测试验证跨会话访问、分析缓存与服务不可用时的规则回退。

## 运行方式

```powershell
ollama pull qwen3-vl:2b-instruct
python -m backend --provider local-model --local-model-url http://127.0.0.1:8787 --enable-video-semantics
```

后端命令行语义开关默认关闭。校园 HTTPS 后端 0.6.0 已单独启用 Ollama。本机回环端口为 11434，模型权重约 1.9 GB，服务器限制为 12 个 CPU 线程。一次获准 CG 输入的蓝色 T 恤与黑色长裤生成耗时 7.51 秒，随后语义分析 11.44 秒，返回简约、日常、蓝色、黑色。五条视频具有模型匹配依据。重复请求复用了标签，结束会话后结果已撤销访问。镜子上的 0.6.0 语义流程待现场验收。
