# 单件 3D 样件 Android 软件接入

2026-11-04。负责人授权先做软件接入；本轮只完成第一阶段的离线人台预览。App 为 `0.4.0-mock` / versionCode 13，沿用 applicationId 与负责人原调试签名。源码与可审阅验证入库，品牌样件资源、截图和含包 APK 只留本机。

## 已接入与明确边界

- 首页「3D 人台样件（实验，不开启摄像头）」独立进入。普通游客试衣会话中不额外嵌入这个实验 Activity，以保留其超时/清理逻辑；诊断使用的非游客试衣页也有入口。
- 同一 v4 蓝色上衣 GLB、原纹理、183 个预计算样本在 Android WebView/WebGL2 显示。站立/抬臂/前伸/转身、六视角、单指旋转/双指缩放、人台/线框与循环可用；竖屏改为上下布局。
- 资源随 APK 离线打包，不访问电脑 Python 服务器或试衣后端。Gradle Sync 只复制指定运行文件/Three.js 依赖/许可；PNG、GLB、动作摘要及几何版本核验后才打入包。原 PNG 没有编辑。
- 资源缺失或 `-PincludeGarment3d=false` 显示缺包说明，可返回常规入口；CI 使用此模式，**其 APK 不包含品牌蓝色样件**，不能拿 CI 缺包 APK 当作本机完整演示版本。
- 使用 [Android 官方本地内容方式](https://developer.android.com/develop/ui/views/layout/webapps/load-local-content)提供 APK 内的 HTTPS origin；依赖固定 `androidx.webkit:webkit:1.12.1`。网络加载关闭且未知请求返回 404，不允许文件/内容 URL、下载、相机/定位授权或任意原生 JS 桥。
- 进入前停掉原相机/感应，返回后保持关闭。后台暂停渲染，恢复不将停留时间计入动作；销毁时释放视图/循环/纹理与 GPU 资源。渲染进程退出会显示本地重试，重新创建独立 WebView。

**当前仍是模拟人台，不是真人 3D 试衣。** 之前镜子真人验证的是原二维图片变形链路。下一阶段必须接人体姿态、体型/尺寸、相机投影、手臂遮挡，再验证自然动作和目标镜子性能；不能把现有三个固定姿态片段直接称为任意真人运动驱动。未调用相机、COS/Aidge、服务器生成或神经网络权重，公共视觉/HTTP 合同未变。

## 软件验证

环境：Windows 构建、JDK 21.0.10 / Gradle 8.11.1 / compileSdk 35；Android 15 API 35 x86_64 模拟器，WebView `124.0.6367.219`，SwiftShader 软件 GPU、前后相机均设 none。横屏 1920×1080 / density 240，并切换竖屏；这不是目标 RK3588 或实体摄像头。

- `:app:assembleDebug :app:assembleDebugAndroidTest :app:testDebugUnitTest :app:lintDebug` 通过；App JVM 32 项通过，含 2 项本地来源/路径/导航策略测试。
- `npm test` 12 项通过，新增后台暂停、恢复时钟和关闭后迟到回调不能重启渲染两项；Python 路由 2 项、合同检查、`git diff --check` 通过。
- 包含资源的 APK：2 项仪器测试通过（24.812 秒）。实际蓝色模型像素检查；俯视抬臂、前伸、循环、后台帧冻结/恢复、竖屏无横向溢出；主动终止 WebView 渲染进程后可重试并重新就绪。首页进入和返回后人体感应仍关闭。
- 缺包 APK：`-PincludeGarment3d=false` 构建通过，1 项仪器测试通过（3.881 秒），显示缺包说明且不创建 WebView，返回正常。
- 首轮验证发现按钮选择器与新状态属性同名，已改为显式 button 选择器及独立 activePose 属性，再运行以上测试；不把失败的首轮算为通过。

本机日志及合成人台截图位于工作区 `work/android3d-20261104/`，不随 PR 上传。按钮由仪器测试调用页面控件，实体触摸/双指手势仍待现场确认。CI 只执行源码构建/单测/lint和三维工具回归，不执行这些带私有纹理的仪器用例。模拟器显示的渲染 FPS 受软件 GPU 影响，不报告为镜子性能或布料求解速度。
