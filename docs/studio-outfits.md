## 素材

来源均为 UNIQLO 官网的商品正面展示图：AIRism 宽松 T 恤（黑/蓝/红，图像商品号 465185）、褶裥长裤（462197）、HEATTECH 针织帽（478303）。[清单](../backend/assets/studio/manifest.json) 记录逐件官网链接、原图链接、尺寸、锚点、原图/透明图 SHA-256 和处理方式。上衣选择 WesternCommon 的平铺展示图，未使用模特穿着图。

使用内置 image_gen 对每件图做透明背景提取，提示词见 [处理记录](../backend/assets/studio/README.md)。原图保存在负责人本地素材工作目录。处理图是辅助去背景版本，可能改变边缘/细节，不声称逐像素保真；实物尺寸和颜色校准未验证。

品牌图片未标为开放许可。原图和处理 PNG 存在本地，不提交到 Git；仓库保留元数据和代码。负责人提供单独的课程素材 ZIP，团队安装到本机后端即可，APK 从同一后端加载，不需另把图片塞入 Android。

## 首次运行

使用项目已有 Python 3.12 环境，在仓库根目录执行：

```powershell
python tools/install_studio_assets.py "收到的商品素材包.zip"
python tools/install_studio_assets.py --check
python -m backend --port 8000 --catalog-db data/catalog.sqlite3
```

安装器核对全部文件、尺寸及 SHA-256 后才写入；拒绝未知路径、重复文件或校验失败。缺包时 API 明确返回 ASSET_NOT_INSTALLED，不偷偷显示旧合成素材。已有旧版目录会在首次升级时替换四个内置条目并保留自建条目；刻意清空的目录不重新种入，升级后的再次打开也不恢复用户删除的商品。

目录上限仍为 50：接近满额时保留自建条目，只按剩余容量加入新内置商品。正常演示与 regression 回归数据库仍应分开；切回正常目录时旧回归条目也会进行一次升级。

Android 模拟器填 `http://10.0.2.2:8000`；普通安卓手机沿用 ADB reverse 或已配置的局域网方式。重新构建本轮 APK，旧客户端与 HTTP 0.2.0 的新增 category 枚举不能混用。

## 怎么试

1. 点击连接服务；先选择合成样例检查运行，只有主动选择 RGB 才用于真人预览。
2. 选一款上衣，再选裤子、帽子。每次选择自动更新当前品类，其他品类保留；一类最多一件。
3. “加入搭配”可重新加回当前单品，“移除本类”移除选中品类，“清空搭配”移除全部。旋转屏幕保留搭配；结束会话清空搭配及素材 Bitmap。
4. 打开关键点显示，观察相同镜像下的背景、点与商品。裤子要拍到双髋、膝盖和脚踝；帽子要有可靠双耳。缺少某品类需要的点，只隐藏该品类。

上衣仍用四点投影。裤子按髋/膝/踝分段三角贴图，保留源图腿缝透明区；双腿交叉/退化或缺点时隐藏，不复用历史腿部。帽子以双耳做旋转/缩放，适合正面，未做精细头发遮挡或人脸网格。它们都是二维预览，不测合身度，也不是三维布料仿真。

OBJ 网格仅替换上衣实验层；裤子和帽子保持照片层。整套搭配不套用躯干近似深度平面。生成按钮只作用于当前选中的可生成上衣，仍明确 MOCK；裤子/帽子不伪装成已接真实 AI。
