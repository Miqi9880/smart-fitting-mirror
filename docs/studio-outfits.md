## 安装运行

向负责人取得 **smart-fitting-mirror-studio-assets-20261023-v4.zip**（透明运行包），不要混用带51张JPEG的原图来源包。运行包SHA-256：

```text
70b6c9af7fefd50037ee935e9b377d71bace46a87dee32c5b8509499938cfbd2
```

在仓库根目录使用现有 Python3.12：

```powershell
python tools/install_studio_assets.py "smart-fitting-mirror-studio-assets-20261023-v4.zip"
python tools/install_studio_assets.py --check
python -m backend --port 8000 --catalog-db data/catalog.sqlite3
```

安装器先核对全部文件、尺寸、RGBA和哈希再写入，拒绝未知路径／重复／缺失文件；缺包API返回503 ASSET_NOT_INSTALLED。运行包不能替代APK；已有0.3.5无需因本次下架重装APK。模拟器填 http://10.0.2.2:8000；普通安卓手机沿用ADB reverse或已配置的局域网地址。

旧v3的51件包仍可安装：安装器只校验／安装当前48件，忽略三张已下架卫衣。更新后端并重新启动，会把SQLite旧目录引用下架素材的条目及改名副本移除；不覆盖其他编辑、不恢复已删除项，空衣柜仍为空。已有会话要重新连接服务才能刷新；不必为目录更新重装APK。

目录上限升到100。SQLite revision2→3仅补新内置ID，不恢复之前删除的五件、不覆盖已编辑条目；刻意清空的目录保持空。旧回归四件会一次性替换，所有迁移保留自建条目，仅按余量添加，重新打开不重复回填。CLI与游客衣柜均在满额时允许更新／删除、拒绝新增。正常与 regression 数据库继续分开。

## 怎么试

1. 连接服务，再点“合成样例”；连接本身不打开相机。真人验证须用户主动选 RGB。
2. 可以选择“上衣＋一种下装＋帽子”，也可以“连衣裙＋帽子”。选连衣裙自动移除上衣和下装；选上衣或下装会退出连衣裙，长裤／半裙／短裤互相替换。
3. “加入搭配”“移除本类”“清空搭配”继续可用；旋转保留选择，退出清理 Bitmap 和会话。缩略图同时最多3个加载，避免48件全量解码造成瞬时内存峰值。
4. 长裤按髋／膝／踝分腿；半裙保持整片裙摆，连衣裙另外对齐肩部和躯干；短裤只覆盖髋到膝之间，不套长裤到脚踝。帽子用双耳；长裙需要可靠腿部，短裙／短裤不要求踝点。缺少所需点时隐藏对应品类，不使用历史点。
5. 关键点默认显示，开关与镜面显示一起放在预览上方。点和线带黑描边，并按屏幕尺寸绘制，避免高分辨率摄像头缩小后看不清；找不到可靠点时不会编造骨架。
6. 选中单品后点“调整本类贴合（大小／位置）”，可改宽度、纵向尺寸、上下位置，并恢复本类默认值。各品类互不影响，换颜色沿用本类参数，旋转保留。默认不跨进程保存；开启“记住本机贴合设置”后保存本机非默认数值，关闭后清除磁盘覆盖，本次值继续可用、下次进程回默认。仅调整照片模式的二维预览，不改变上传原图或后端尺码，不是实际量体。帽子需正面可靠双耳，当前没有单独的人脸检测／身份识别功能。
7. 长裤默认宽度与纵向尺寸均112%：围绕各自髋—膝—踝位置分别扩宽裤腿，并以髋部为基准延长，上下偏移保持0。不会通过放大两腿间距来撑宽裤子。想再微调时仍使用“调整长裤贴合”，帽子、上衣和裙裤参数独立。
8. 多通道USB相机可点“相机通道”，选择ID并确认；只选通道不会自动开启摄像头，已在RGB预览时切换会重新绑定。所选ID旋转保留；拔插后编号可能变化，显式ID不可用时会报错，不悄悄改选另一相机。当前Gemini2在本次连接中ID5为已验证彩色通道，不把该编号硬编码为通用规则。镜子调试连接与ADB转发见[现场调试说明](mirror-debugging.md)。
9. 点预览前的“全屏预览”，用＋/－或双指在100%–300%之间查看细节，放大后单指拖动；“恢复全景”归零缩放和位置。“退出全屏”或系统返回键恢复设置页。数字放大可能裁掉部分身体，也不增加原相机细节。全屏不启动或重绑摄像头。
10. “上衣避开头部（近似）”默认开启，只在当前双耳可靠时保留头部RGB，减少上衣贴图误遮头部；可关闭比较。独立帽子不受此裁剪。缺耳/侧脸不能保证避脸，不是分割或精细遮挡；OBJ实验不启用这项照片裁剪。

长度字段 hem_ratio、各类别源控制点与互斥规则见 [HTTP接口](interfaces/backend.md)。这些是初始二维标定，不是量体、三维布料或精细遮挡。OBJ实验只替换上衣层；整套搭配不套躯干近似深度面。上衣仍每次一件；当前不支持两件上衣内外叠穿。

生成只接受单件 garment_id，默认仍为MOCK，可选Aidge真实上衣生成已在镜子跑通，见[验证记录](reports/mirror-real-generation-2026-10-23.md)；连衣裙／裤子／半裙／短裤／帽子暂只实时预览。外部模型的支持品类由后端成员实测后接，不随新图片自动宣布完成。
