# 原创演示上衣

本目录 PNG 由本仓库 [create_assets.py](../create_assets.py) 用几何图形绘制，不含人像、外部商品照片或商标。仅用于课程开发和接口联调；不能证明真实试衣效果。

- 尺寸：600 × 800，RGBA，正面、未镜像、透明背景。
- upper_blue、upper_sand 可请求模拟生成；upper_preview 仅供预览，用于验证 generation_reference_url=null 的 422 分支。
- 双肩：穿着者左肩 (0.75, 0.15)、右肩 (0.25, 0.15)。
- 双髋：穿着者左髋 (0.70, 0.85)、右髋 (0.30, 0.85)。左右采用解剖学约定；髋点是躯干对齐位置，不是衣服下摆端点。
- 图像及其生成脚本由项目先行实现阶段提供。素材许可：CC0-1.0；该声明只覆盖这三个原创 PNG 和对应绘制数据，不改变其他代码的许可。

重建：在仓库根目录运行 `python -m backend.create_assets`。测试会检查图片透明通道、尺寸以及四个锚点是否落在衣服上。Android 中的实际对齐与跟随仍需 T05 验证。
